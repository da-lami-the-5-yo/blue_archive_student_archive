# Blue Archive Complete Multilingual Student & Art Archive (299 Students / Variants)
# 블루 아카이브 전원(299명) 다국어 데이터셋 및 아트 아카이브

본 리포지토리는 넥슨게임즈의 모바일 게임 **블루 아카이브(Blue Archive / ブルーアーカイブ)**에 등장하는 **정식 출시 학생, 미출시 학생, 미출시 시즈널 의상 전원(총 299건)**의 다국어(한국어, 영어, 일본어) 프로필과 이미지 데이터를 체계적으로 수집·분류·백업한 통합 아카이브입니다.

---

## 1. 디렉토리 구조 표준 (Directory Structure)

본 프로젝트는 요청된 명세에 따라 `학교명/동아리명/학생명/시즈널`의 엄격한 계층 디렉토리 구조를 따릅니다.

```
blue_archive_data/
├── [학교명]/
│   └── [동아리명]/
│       └── [학생명]/
│           └── [시즈널]/
│               ├── info.json              # 다국어 프로필, 전투 정보, 이미지 통계
│               ├── 공식/                  # 공식 일러스트 및 인게임 스탠딩 CG
│               ├── 준공식/                # 공식 코믹스, 애니메이션, 미디어믹스 일러스트
│               └── 비공식/                # SFW 검증 및 공식 화풍 유사도 랭킹 팬아트
│                   ├── rank00/            # 유사도 최상위 (Official resemblance ≥ 0.65)
│                   ├── rank01/            # 유사도 상위 (0.50 ≤ resemblance < 0.65)
│                   └── rank02/            # 유사도 보통 (0.35 ≤ resemblance < 0.50)
├── students_master_database.json          # 전체 299명 마스터 데이터베이스 (JSON)
├── index.html                             # 다국어 지원 인터랙티브 갤러리 및 검색 대시보드
└── README.md                              # 본 프로젝트 종합 안내 문서
```

- **전체 데이터셋 규모**: 총 299명 (정식 출시 194명, 미출시 학생 64명, 미출시 시즈널 41벌)
- **정보 출처**:
  - 나무위키(Namuwiki): [블루 아카이브/등장인물](https://namu.wiki/w/%ED%8B%80:%EB%B8%94%EB%A3%A8%20%EC%95%84%EC%B9%B4%EC%9D%B4%EB%B8%8C/%EB%93%B1%EC%9E%A5%EC%9D%B8%EB%AC%BC) 및 [미출시 학생](https://namu.wiki/w/%EB%B8%94%EB%A3%A8%20%EC%95%84%EC%B9%B4%EC%9D%B4%EB%B8%8C/%EB%AF%B8%EC%B6%9C%EC%8B%9C%20%ED%95%99%EC%83%9D) 카탈로그

  - 영어 및 일본어 검색 태그(`search_tags`) 기본 탑재

## 3. 이미지 수집 및 분류 파이프라인

본 리포지토리에 포함된 수집 도구(`blue_archive_collector.py`)는 다음과 같은 컴퓨터 비전 및 머신러닝 파이프라인을 탑재하고 있습니다.

1. **다국어 확장 검색 쿼리 풀 (Multilingual Search Pool)**
   - 한국어 이름 (예: `나나가미 린`, `쿠치나시 유메`)
   - 영문 및 보루 태그 (예: `nanagami_rin`, `kuchinashi_yume`, `blue_archive`)
   - 일본어 공식 표기 (예: `七神リン`, `クチナシ・ユメ`)

2. **비공식 팬아트 안전 검사 (SFW Safety Filtering)**
   - NudeNet / Pillow / SafeBooru Rating 시스템을 연계하여 성인물 및 선정적인 요소를 100% 필터링하고 전연령 안전(SFW) 일러스트만 수집

3. **공식 화풍 유사도 랭킹 (Art Style Similarity Evaluation)**
   - 공식 일러스트와 팬아트 간의 **HSV 색조 히스토그램 상관관계(Histogram Correlation)** 및 **ORB 특성점 코사인 유사도(Feature Cosine Similarity)**를 가중 결합하여 점수를 산출
   - 유사도 점수에 따라 `rank00`(최상위), `rank01`(상위), `rank02`(보통) 디렉토리로 자동 격리 분류

## 5. 실행 및 브라우징 방법

### 1) 인터랙티브 갤러리 웹 대시보드
`blue_archive_data/index.html` 파일을 웹 브라우저로 열면 다음과 같은 기능을 이용할 수 있습니다:
- 다국어 실시간 검색 (한국어, 영어, 일본어 지원)
- 정식 출시 / 미출시 학생 / 미출시 시즈널 필터링
- 이미지 보유 학생 필터링
- 공식, 준공식, SFW 랭크별 일러스트 갤러리 모아보기

### 2) 추가 수집 도구 실행
특정 학생이나 전체 학생에 대해 추가 이미지를 수집하려면 터미널에서 아래 명령을 실행할 수 있습니다:
```bash
# 특정 학생 검색 및 추가 수집
python3 blue_archive_collector.py --student "시치도 유키노"

# 미출시 학생 전체 다운로드 실행
python3 blue_archive_collector.py --unreleased-only
```
